Choose your runner

兩種版本，對應不同使用方式

Chrome / Edge Extension

DOM / JavaScript Runner

安裝成瀏覽器擴充功能後，可固定在右側 Side Panel。適合你已經開著目標網頁，需要在指定時間從目前分頁直接執行 JSON 流程。

  • 使用目前分頁，不需要另外啟動瀏覽器。
  • 支援開始倒數、取消倒數、從指定步驟開始。
  • 適合手動開頁、現場快速調整 selector 與文字條件。
查看 DOM Extension 介紹

Playwright CLI / Web UI

Playwright Runner

透過 Playwright 啟動瀏覽器並執行相同 JSON 流程。適合需要固定環境、可重複測試、用 UI 或 CLI 跑完整流程的情境。

  • 提供 Web UI，可填 URL、貼 JSON、設定 headless 與 slowMo。
  • 支援秒級倒數、立即執行、流程狀態與事件紀錄。
  • 適合自動化測試、練習站驗證、CLI 腳本化執行。
