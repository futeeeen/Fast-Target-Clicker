# Fast Target Clicker DOM / JavaScript Extension

這個資料夾就是可安裝的 Chrome/Edge 擴充功能本體。此版本透過 content script 在目前分頁內尋找 DOM 元素，並模擬 JavaScript 點擊、選取與勾選事件。

## 安裝方式

1. 打開 Chrome 或 Edge。
2. 進入 `chrome://extensions` 或 `edge://extensions`。
3. 開啟「開發人員模式」。
4. 點「載入未封裝項目」。
5. 選擇這個 `packages/dom-js-extension` 資料夾。

安裝後，點工具列上的 Fast Target Clicker 圖示，就會在瀏覽器右側開啟工具面板。
