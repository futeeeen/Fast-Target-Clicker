Fast Target Clicker
功能 流程 範例 安裝 使用方式

Chrome / Edge workflow automation

把指定時間、條件判斷與多步驟點擊整理成一套可重複使用的流程。

Fast Target Clicker 讓你用 JSON 設定頁面操作：等待目標出現、依文字篩選、選擇下拉選單、勾選 checkbox，並在右側 Side Panel 追蹤目前執行到哪一步。

  },
  {
    "type": "select",

  }
]

Core features

為不確定的頁面狀態設計

不需要把每次情境寫死。可以先準備通用規則，再依當天拿到的資訊修改 selector、文字條件或指定步驟。

01

右側固定面板

使用 Chrome Side Panel 顯示工具，頁面切換時仍可在右側查看設定、倒數與執行狀態。

02

指定時間啟動

設定開始時間後由背景服務排程，到時間自動對目前記錄的分頁觸發流程。

03

多步驟 JSON

支援 click、select、check、fill，適合跨頁流程、表單流程與需要依序操作的情境。

04

自動等待目標

每一步可設定 waitForMs 與 pollMs，目標還沒出現就持續檢查，逾時會顯示 not found。

05

文字條件篩選

用 textIncludes、textExcludes 或多組 textIncludes_1、textIncludes_2 判斷狀態文字。

06

從指定步驟開始

測試或補救時可以從第 N 步往下跑，不必每次都從第一頁重新開始。

How it works

四個步驟完成一套流程

把當天取得的資訊轉成 JSON，先手動測試，再交給指定時間自動啟動。

  1. 1

    確認目標

    從網頁檢查元素取得 CSS selector，或使用按鈕文字、包含文字與排除文字。

  2. 2

    組成 JSON

    依序寫下 click、select、check、fill，每一步都可以有自己的等待時間。

  3. 3

    立刻測試

    按下立刻測試會先儲存設定，再從指定步驟開始執行，狀態區會顯示卡在哪一步。

  4. 4

    設定時間

    保持目標頁面開著，到指定時間時由背景排程觸發同一套流程。

Install

只要載入 extension 資料夾就能安裝

專案根目錄保留文件、產品介紹頁與測試頁；真正的擴充功能本體集中在 extension 資料夾。分享或安裝時只需要這個資料夾。

  1. 1

    打開 Chrome 或 Edge，進入 chrome://extensions 或 edge://extensions。

  2. 2

    開啟「開發人員模式」，點選「載入未封裝項目」。

  3. 3

    選擇專案內的 extension 資料夾。

  4. 4

    安裝後點工具列圖示，工具會在瀏覽器右側 Side Panel 開啟。

Scheduled run

指定時間一到，自動觸發同一套流程

在右側面板設定「指定開始時間」並儲存後，工具會用背景排程記住目標分頁。時間到時，它會等同按下「立刻測試」，從設定的起始步驟開始執行 JSON 流程。

先開好目標頁

排程會對儲存設定時記錄的分頁觸發，因此正式使用前先把目標頁面開好並停在正確起點。

先用立刻測試確認

手動測試會使用同一份 JSON 與同一個起始步驟。測得過，指定時間觸發才有可預期結果。

狀態區會顯示卡點

執行中會顯示目前第幾步、目標條件與逾時結果，方便調整 waitForMs、pollMs 或 selector。

User guide

欄位怎麼改

大多數情境只需要修改 selector、文字條件、value 與等待時間。先用立刻測試確認，再設定指定時間。

selector

最精準的定位方式，例如 #submit、.buy-button、#gameList button。如果 id 以數字開頭，複製到 JSON 時要保留跳脫符號。

textIncludes

陣列內是 AND，全部文字都要出現在同一個元素內才會符合。適合判斷「區域 + 價格 + 狀態」。

textIncludes_1 / _2

不同組之間是 OR，每一組內仍是 AND。適合「A 區可買」或「B 區可買」都可以點的情境。

textExcludes

排除不想點的狀態，例如已售完、不可購買、暫停銷售。符合排除文字的元素會被跳過。

waitForMs / pollMs

waitForMs 是最多等待多久，pollMs 是多久檢查一次。沒有設定時預設最多等 10000ms、每 500ms 檢查一次。

nextDelayMs

成功完成某一步後，額外等一段時間再進下一步。適合已知網站需要動畫或固定轉場時間的頁面。

Step types

支援的動作

click 點擊符合 selector 或文字條件的元素。
select 選擇下拉選單指定 value。
check 勾選 checkbox，已勾選時不會重複切換。
fill 填入 input 或 textarea 的 value。
