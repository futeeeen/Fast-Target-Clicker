Fast Target Clicker
多頁流程 文字條件 表格 selector 延遲載入

Practice lab

練習各種真實頁面會遇到的點擊情境。

這個測試站刻意放入動態按鈕、重複文字、售完狀態、表格列、數字開頭 id、延遲出現與表單欄位。打開右側工具面板，把範例 JSON 貼進去即可練習。

建議練習順序
  1. 先用「多頁流程」確認 click/select/check。
  2. 再用「文字條件」練習 textIncludes 與 textExcludes。
  3. 最後測試延遲載入與指定時間觸發。

Scenario 1

多頁流程與表單

從第一步開始，點擊後產生三個同名按鈕，再進入座位頁與表單頁。這是最接近完整流程的練習。

範例 JSON

[
  {
    "type": "click",
    "selector": "#firstButton"
  },
  {
    "type": "click",
    "text": "趕快點我"
  },
  {
    "type": "click",
    "selector": "#secondButton"
  },
  {
    "type": "click",
    "selector": "div.seat-item",
    "textIncludes": ["特C區", "5990"],
    "textExcludes": ["已售完"],
    "waitForMs": 10000
  },
  {
    "type": "select",
    "selector": "#ticketCount",
    "value": "2"
  },
  {
    "type": "check",
    "selector": "#agreeTerms"
  },
  {
    "type": "click",
    "selector": "#finishButton"
  }
]

Scenario 2

依狀態文字判斷要點哪一個

selector 都是同一種元素，但狀態文字不同。練習使用 textIncludes、textIncludes_1 / textIncludes_2 與 textExcludes。

範例 JSON

[
  {
    "type": "click",
    "selector": ".area-item",
    "textIncludes_1": ["特C區", "5990", "剩餘"],
    "textIncludes_2": ["特D區", "5990", "熱賣中"],
    "textExcludes": ["已售完", "暫停銷售"]
  }
]

Scenario 3

表格列與數字開頭 id

練習從 DevTools Copy selector 取得第 2 列按鈕，也練習像 #\32 2437_6 這種需要跳脫的 id。

場次 日期 狀態 操作
第一場 06/01 可購買
第二場 06/02 可購買

範例 JSON

[
  {
    "type": "click",
    "selector": "#gameList > table > tbody > tr:nth-child(2) > td:nth-child(4) > button"
  },
  {
    "type": "click",
    "selector": "#\\32 2437_6"
  }
]

Scenario 4

延遲載入與等待

按下準備按鈕後，目標會延遲 3 秒才出現。練習 waitForMs 與 pollMs，不必猜 nextDelayMs。

範例 JSON

[
  {
    "type": "click",
    "selector": "#prepareDelayed"
  },
  {
    "type": "click",
    "selector": "#delayedTarget",
    "waitForMs": 8000,
    "pollMs": 250
  }
]
