# DOM / JavaScript Runner

這是 Fast Target Clicker 的 Chrome/Edge 擴充功能產品線。

## 資料夾

- `extension`: 可用「載入未封裝項目」安裝的擴充功能本體。
- `docs`: 產品介紹網站與公開練習站。

## 安裝

1. 打開 Chrome 或 Edge。
2. 進入 `chrome://extensions` 或 `edge://extensions`。
3. 開啟「開發人員模式」。
4. 點「載入未封裝項目」。
5. 選擇 `C:\futen\Project\Auto-click\dom-js-runner\extension`。
