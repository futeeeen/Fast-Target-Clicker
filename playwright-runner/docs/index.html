Playwright CLI / Web UI

用 Playwright 執行可重複測試的多步驟流程。

Playwright Runner 使用和 DOM Extension 相同的 workflow JSON，但由 Playwright 啟動瀏覽器並執行流程。適合自動化測試、固定環境驗證、CLI 腳本化執行，以及透過 Web UI 操作。

安裝方式 設定範例

Web UI

填入目標 URL、貼上 workflow JSON、設定起始步驟、slowMo、headless 與指定時間。按下「立刻執行」會馬上開始；按下「開始倒數」才會進入排程倒數。

CLI Runner

可用 `npm start -- --url ... --workflow ...` 在命令列執行同一份 JSON，適合固定流程、批次測試或和其他工具串接。

狀態回報

執行時會回報目前步驟、等待狀態、找不到目標的錯誤，以及流程完成訊息，方便判斷卡在哪一步。

Install

安裝與啟動 UI

第一次使用先安裝套件與 Chromium，之後可直接啟動 UI。

cd C:\futen\Project\Auto-click\playwright-runner\package
npm install
npx playwright install chromium
npm run ui

Default target

預設練習站

UI 預設目標 URL 會指向公開練習站，可直接載入練習站範例 JSON 測試。

https://futeeeen.github.io/Fast-Target-Clicker/practice/

Workflow JSON

練習站流程範例

這份 JSON 會依序點第一頁按鈕、選任一快速按鈕、進入座位頁、選擇 5990 座位、選數量、勾選 checkbox 並完成。

[
  { "type": "click", "selector": "#firstButton" },
  { "type": "click", "selector": "#quickButtons .quick-button" },
  { "type": "click", "selector": "#secondButton" },
  {
    "type": "click",
    "selector": "div.seat-item",
    "textIncludes": ["5990"],
    "waitForMs": 10000
  },
  { "type": "select", "selector": "#ticketCount", "value": "2" },
  { "type": "check", "selector": "#agreeTerms" },
  { "type": "click", "selector": "#finishButton" }
]

CLI

命令列執行

若不需要 UI，也可以直接用 CLI 跑同一份 workflow。

npm start -- --url https://futeeeen.github.io/Fast-Target-Clicker/practice/ --workflow examples/practice-flow.json
